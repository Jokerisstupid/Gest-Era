# GestEra

Write in the air. Learn with AI.

Build a local-first gesture-controlled whiteboard for students and teachers. No login is required for drawing. Camera processing stays on the device. Mouse, touch, pen, and hand input share one drawing pipeline. Pinch is pen-down; pointing only moves a cursor. Separate the drawing hand from command gestures. End disconnected strokes safely.

Use small TypeScript modules, a React application, Canvas layers, IndexedDB persistence, explicit error states, keyboard access, responsive layouts, and measured claims. Do not generate fake projects, tracking coordinates, AI results, performance statistics, or tutorial completion checks. Templates are clearly identified starting content.

1. Foundation: routes, design tokens, reusable controls, IndexedDB repository, dashboard and settings.
2. Vision: real MediaPipe two-hand tracking, camera lifecycle, active region, lighting warnings, measured diagnostics, real landmark recording.
3. Gestures: scale-independent features, hysteresis, debounce, holds, cooldowns, smoothing, loss handling, interactive tutorial, recorded fixture tests.
4. Board: pen/highlighter/eraser, selection and transforms, text/shapes, history, pages/backgrounds, zoom/pan, autosave, import and PNG/PDF/editable exports.
5. Workspace refinement: project management, settings, command palette, gesture reference.
6. AI: server-only Gemini credentials, bounded user-selected snapshots, schema validation, rate limiting, transcription confirmation and independent math verification.
7. Presentation/accessibility/voice.
8. Optional cloud sync and classroom after the local app is stable.
9. Hardening, realistic measurement and portfolio packaging.
